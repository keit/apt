keit APT repository

Linux apps by Kei Takashima (ZL2MIM), for Debian 12 or newer, Ubuntu 24.04 or newer and Raspberry Pi OS (64-bit). PCs (amd64) and Raspberry Pi (arm64).

Set up (once)

sudo curl -fsSLo /usr/share/keyrings/keit.gpg https://keit.github.io/apt/keit.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/keit.sources https://keit.github.io/apt/keit.sources
sudo apt update

Then install any package below, e.g. sudo apt install dv3kclient. New versions arrive with your normal system updates.

Signing key

Fingerprint:

2F13 9F75 C569 FA77 1904 732E E594 4DBB D89D D18E

To check the key you downloaded: gpg --show-keys /usr/share/keyrings/keit.gpg

Remove

sudo rm /etc/apt/sources.list.d/keit.sources /usr/share/keyrings/keit.gpg
sudo apt update
